# ezyTailor Store

Official ezyTailor Store web app — tailored tools, pattern scales, fusing bukram, threads, scissors, and bluetooth receipt printers for tailors.

## How to Publish on GitHub Pages

1. Create a new repository on GitHub (e.g., `ezytailor-store`).
2. Upload the **contents** of this folder (`index.html`, `css/`, `js/`, `assets/`, `.nojekyll`) directly into the repository root (do **not** upload the outer `ezyTailor Store` folder itself).
3. On GitHub, go to **Settings** → **Pages**.
4. Under **Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.
5. Your store will be live at `https://<your-username>.github.io/<repo-name>/`!
